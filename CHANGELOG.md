# Changelog

This file records notable, learner-facing changes to Nihao World. Small copy
edits, routine maintenance, and internal refactors may remain in Git history
without receiving their own release entry.

## Unreleased

## v1.1.0 — 2026-09-10

### Added

- Added the Nihao World zongzi favicon for browser tabs and eligible Google Search results.
- Added search discovery metadata, an automatically generated sitemap, and crawler guidance.
- Added the bilingual Culture Story “The Frog in the Well” (井底之蛙).
- Added the bilingual Culture Story “The Archer and the Oil Seller” (卖油翁：熟能生巧).

### Changed

- Made the main titles on all four About pages more compact, especially on phones.
- Renamed “Why I built it” to “Why We Build It” on the Creator & the Project page.
- Removed the public GitHub repository link from the Creator & the Project page.

## v1.0.0 — 2026-09-10

### Added

- First formally versioned public release of Nihao World.
- Interactive Chinese learning organized by topics and textbook lessons.
- A child-friendly Culture library with stories at multiple reading levels.
- Recorded Mandarin audio, visual vocabulary, and interactive practice activities.
- Public project, research, feedback, privacy, and safety information.

## Versioning policy

- A small number of new stories or routine improvements remain under Unreleased.
- A meaningful group of new stories or a new learner-facing feature increments the
  minor version, such as v1.1.0.
- A production bug fix increments the patch version, such as v1.0.1.
- A major redesign or incompatible change to the site's structure increments the
  major version, such as v2.0.0.
