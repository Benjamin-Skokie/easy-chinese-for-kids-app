# Is It?

Status: `implemented` — optional Topic enrichment
URL: `index.html?topic=is-it#topic-detail`

## Scope and evidence

This is not mapped to a textbook lesson. It is a deliberately labelled Time & Daily Life enrichment topic that gives the existing `shi-bu-shi-meimei-package.webp` contrast visual a narrow, concrete owner.

## Page blueprint

| Section | Decision |
| --- | --- |
| Scene | One native 2:1 two-panel contrast visual: sealed package → Meimei under the box. The full exchange is `这是不是包裹？` / `不是，这是美美。` |
| Book words | Text-only: `是`, `不是`, `包裹`, `妹妹`. |
| Useful note | `是不是……？` asks “Is it…?”; answer with `是` or `不是`, then identify the object or person. |
| Practice | One Look and choose game. It shows either the left or right panel, asks `这是不是包裹？`, and offers the two complete answers. The sole green New game button chooses a different panel. Wrong choices show red feedback; the correct choice turns green, displays the complete answer in Hanzi/Pinyin/English, and speaks it. |

## Ownership

The scene owns the package-surprise exchange. The text-only Book words own the vocabulary, the Useful note owns the reusable question pattern, and practice owns choosing the complete visual answer. This topic does not claim book coverage.
