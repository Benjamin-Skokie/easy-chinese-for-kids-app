# Colour Language Audit

Last updated: 2026-08-09

This is the implementation checklist for colour language across the Easy Steps books. It separates language that children should practise in the app from workbook-only colouring instructions.

## Core language patterns

| Pattern | Book evidence | App implication |
| --- | --- | --- |
| `颜色` | 1B Lesson 6 introduces `红色、黄色、蓝色、绿色`; 2A Lesson 7 adds `紫色、橙色、粉红色、黑色、白色`. | Teach the complete nine-colour set cumulatively. |
| `人 + 喜欢 + 颜色` | 1B: `丁一喜欢红色。乐乐喜欢黄色。甜甜喜欢蓝色。晶晶喜欢绿色。`; 2A: `我喜欢紫色。` | Use listening and speaking prompts about a person’s favourite colour. |
| `人 + 不喜欢 + 颜色 + 和 + 颜色` | 2A: `我不喜欢黑色和白色。` | Include positive and negative preference practice. |
| `颜色 + 的 + 名词` | Repeats across fruit, animals, stationery, clothes, transport, rooms, and food. | This is the main transferable grammar pattern; practise the whole phrase, not a standalone colour card. |
| `数量 + 量词 + 颜色 + 的 + 名词` | 2B Stationery: `安安有三支红色的铅笔。` | Connect the colour topic to the stationery sentence builder and measure words. |
| `天上有 / 地上有 + colour + noun` | 3B Nature: `地上有绿树、红花和小草。` | Keep colour inside the Nature descriptions, not as a disconnected colour drill. |

## Where colours recur in the books

| Book / lesson | Colour use | Example language or activity |
| --- | --- | --- |
| 1B Lesson 6 Colours | Base vocabulary; likes; classroom hunt; shape-and-count work. | `丁一喜欢红色。`; hear a colour and touch an item of that colour. |
| 1B Lesson 7 Fruit | Describe fruit and animals by colour. | `红色的苹果、绿色的葡萄、黄色的香蕉、红色的草莓`. |
| 2A Lesson 7 Colours | Five new colours; full phrase matching; likes/dislikes; describe a clown. | `紫色的葡萄、白色的狗、粉红色的鞋`; `他穿紫色的衣服。` |
| 2B Lesson 1 Weekdays | Associate days of the week with colours as a listening/retrieval game. | Hear a colour, then say the matching weekday. |
| 2B Lesson 3 Stationery | Colour inside a counted object phrase. | `红色的铅笔`; `有 + 数量 + 颜色 + 文具`. |
| 3A Lesson 7 Clothes | Describe clothing by colour. | `红色的裙子、蓝色的裤子、橙色的裙子、黑色的皮鞋、白色的皮鞋`. |
| 3B Lesson 1 Schoolbag | Describe school supplies by colour. | `黄色的铅笔、黑色的橡皮、橙色的尺子、粉红色的彩色笔、蓝色的书包`. |
| 3B Lesson 2 Classroom | Describe classroom/clothing/school items by colour. | `黄色的课本、蓝色的校服、红色的练习册、绿色的文具盒`. |
| 3B Lesson 6 Vegetables | Describe food using its original colour. | `白色的鸡蛋`; colour-to-food association game. |
| 3B Lesson 7 Nature | Describe a nature scene with coloured nouns. | `地上有绿树、红花和小草。` |
| 4A Lesson 6 Transport | Describe vehicles by colour. | `蓝色的飞机、黄色的校车、紫色的公共汽车、红色的出租车、绿色的火车`. |
| 4B Lesson 2 Clothes | Use colour-plus-clothing descriptions. | `黄色的衬衫、蓝色的短裤、黑色的长裤、粉红色的裙子、橙色的毛衣、红色的大衣`. |
| 4B Lesson 3 My Room | Use colour-plus-furniture and room-object descriptions. | `粉红色的床、红色的自行车、黄色的书桌、橙色的椅子、绿色的书架、白色的电脑、蓝色的钢琴`. |

## Implementation priorities

1. The Colours topic should provide the reusable base: full phrases, likes/dislikes, a colour hunt, and picture-to-phrase selection.
2. Stationery, Clothes, Schoolbag, Classroom, Transport, and My Room should reuse `颜色 + 的 + 名词` with their own topic objects rather than duplicate a generic colour card deck.
3. Keep `数量 + 量词 + 颜色 + 的 + 名词` in the Stationery flow.
4. Keep the coloured-nature phrase in the Nature flow.
5. Treat worksheet directions such as “colour in the picture” as interaction inspiration, not as standalone language content unless the Chinese instruction itself is part of the lesson goal.
