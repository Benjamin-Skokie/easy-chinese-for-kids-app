# Curriculum Guide

Last updated: 2026-08-09

This is a compact reference for series-wide curriculum questions. It is not required reading for an ordinary topic page; use [lesson_page_workflow.md](./lesson_page_workflow.md) instead.

## When to use this file

Consult it only when a topic returns across books, a grammar family spans several topics, or the intended progression is unclear. For a single new topic, use the relevant OCR, mapping, assets, and one lesson contract.

## Non-negotiable rules

For every mapped lesson, the contract must trace each required word, sentence pattern, dialogue, distinction, and measure word to one of these child-facing surfaces:

- a scene with a meaningful model sentence;
- Book words for focused reference when scenes are not enough;
- a Useful note for a reusable distinction;
- practice that makes the child recognize, choose, complete, build, or say the target language.

Book evidence outranks mappings and asset inventories. Do not mark a lesson complete from an asset folder, a topic title, or a tap-to-hear card alone.

## Progression rules

Returned topics need a new language job. Keep the original knowledge visible, but do not re-skin the same vocabulary drill.

| Language family | Progression to preserve |
| --- | --- |
| `颜色 + 的 + 名词` | Starts with colour vocabulary, then becomes object description across fruit, stationery, clothes, transport, rooms, food, and nature. |
| `喜欢 / 不喜欢` | Begins as personal preference, then returns in food, hobbies, subjects, and leisure with the new topic’s vocabulary. |
| `有 / 没有` | Moves from family possession/counting to schoolbags, classrooms, rooms, and location sentences. |
| `会` | Separates ability from preference; later pages must make that contrast explicit. |
| Time | Moves from day names and whole hours to dates, exact minutes, and routines. |
| Location | Moves from named places to precise relations such as `在...上面 / 里面 / 前边`. |

## Cross-topic reminders

- Use existing art only when it clearly teaches the sentence or contrast at its actual page size.
- Create a new asset only for a proven scene gap; do not generate an illustration merely because a word is new.
- Keep grammar in its natural lesson context. For example, teach `颜色 + 的 + 名词` with the topic object, and teach `有 / 没有` with a meaningful container or location.
- Treat measure words as language content when the book introduces them; do not reduce them to decoration around a noun.

Maintain open source gaps in the relevant contract. A topic may be `needs-content-audit`, `partial`, or `content-complete`; uncertainty is a reason not to invent child-facing language.
