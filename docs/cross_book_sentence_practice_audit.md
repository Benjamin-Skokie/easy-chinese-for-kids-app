# Cross-Book Sentence and Practice Audit

Last updated: 2026-08-09

## Why this audit exists

The existing asset maps answer whether an illustration *could* support a lesson. That is not enough. A lesson is not complete just because an asset folder exists, or because a topic has a list of words.

This document records the learning contract for every ordinary lesson in Books 1A–4B:

1. the sentence patterns the child should be able to understand and say;
2. the progression when a topic returns in a later book; and
3. the kind of interactive practice that proves the pattern is being used, rather than merely displayed.

Source material is the local OCR text in `docs/ocr/`. Sentence wording below uses the textbook patterns where OCR is clear; it is a curriculum-aligned product plan, not a transcription or a reuse of textbook artwork.

## Completion rule

For a lesson to be called complete, its page needs all four layers:

- **Scenes:** meaningful visual contexts for the target sentences.
- **Book words:** the concrete words introduced in that lesson.
- **Useful notes:** one or more logical patterns that help a child generalize, rather than a duplicate word list.
- **Practice:** an interactive listening, choosing, building, sorting, or speaking task that exercises the target pattern.

Tap-to-hear alone is support, not practice. A practice task must randomize the target or choices enough that a child cannot win from screen position or a memorized shape.

## Cross-topic sentence map

| Topic and book sequence | Sentence coverage the site should provide | Practice that fits the language |
|---|---|---|
| **Numbers** — 1A L1–3 | Count objects from 1–20: `一个 / 两个 …` and `有几个？` where appropriate. | Count a changing set of pictured objects; listen-and-tap the total; say the count aloud. |
| **Numbers** — 2A L1, 3A L1 | Read and build 21–40, then 41–100: tens first, then ones. | Number-builder with shuffled tens/ones; quantity board only for smaller believable totals, numeral/listening games for higher totals. |
| **Telephone numbers** — 4A L1 | `你的电话号码是多少？` / `我的电话号码是……`; read digits one by one. | Listen to a short randomized telephone number and tap the digit sequence; then role-play the two-line exchange. |
| **Greetings** — 1A L4 | `你好。` / `您好。` / `再见。` in school, friend, and adult contexts. | Situation chooser: listen to a line, tap the fitting arrival/departure scene; then order a two-line exchange. |
| **Polite words** — 1A L5 | `谢谢。` / `不客气。` / `对不起。` and the classroom use of `请……`. | Pick the right response for a mini-scene, not word-to-translation matching. |
| **Requests** — 3A L6 | `请……。` / `我可以……吗？` / `可以。` / `不可以。` | Choose the polite request for a situation, then build the reply. Use a clear permission contrast. |
| **Names and friends** — 1A L6, 2A L3 | `你叫什么名字？` / `我叫……。`; `他 / 她是我的好朋友。` | Dialogue ordering for name exchange; choose the child being introduced in a friendship scene. |
| **Age** — 1A L7 | `你几岁？` / `我……岁。` | Listen for an age and give the correct child a birthday badge; then say the answer. |
| **Family** — 1B L1–2 | `我爱爸爸 / 妈妈。`; identify `哥哥、姐姐、弟弟、妹妹`. | Tap the named family member in a family scene; listen-and-choose relationship cards. |
| **Family counting** — 2A L2 | `我有……。` / `我没有……。` with `一个 / 两个` and sibling language. | Pack or reveal family-photo cards; child chooses whether the sentence is `有` or `没有`, then builds it. |
| **Family introduction** — 3A L4 | Introduce family members with `这是我的……。` / `他 / 她是我的……。` | Build a small family introduction from a pictured family tree; no generic flashcard review. |
| **Body** — 1B L3–4 | Identify body and face parts; use the book’s point-and-say language. | Audio-led find-and-tap on a child illustration with targets that move/randomize between rounds. |
| **Pets and animals** — 1B L5, 2B L5 | Name pets and animals; include `我有一只……` for pets. | Listen-and-find in a home/zoo scene; sort pets versus other animals only after recognition is secure. |
| **Colours, first pass** — 1B L6 | Colour words as descriptors: `红色的……`, not only isolated colour names. | A rich mixed-object picture where object identity changes and colour fills are randomized each round; child taps the called colour-and-object pair. |
| **Colours, second pass** — 2A L7 | Extend colour descriptions and preferences: `我喜欢……色。` / `我不喜欢……色。` | Picture-to-complete-phrase listening game; object and colour must both change. Include all book colours, not only four. |
| **Fruit and snacks** — 1B L7, 2B L7 | Name fruit/snacks; use `我喜欢吃……` and, when relevant, `我喜欢喝……`. | Shop/basket collection: listen for the food phrase, place the correct item in the right container. |
| **Toys** — 2A L4 | `这是我的……。` with core toy words. | Find the requested toy in a toy-room scene, then use the ownership sentence. Do not mix vehicles in unless the lesson explicitly does. |
| **Reading and hobbies, first pass** — 2A L5 | `我喜欢看书。` and a personal-preference response. | Child chooses a familiar activity, hears the complete sentence, then records/says it back; recognition comes before free choice. |
| **Clothes, first pass** — 2A L6 | Dressing actions: `我会穿衣服。`; `穿……`, `戴……` where introduced. | Dress a child for a stated routine using two or three large clothing choices; then play the completed sentence. |
| **Weekdays** — 2B L1 | `今天星期几？` / `今天星期……。` | Place a changing daily activity on the correct day; ask the question and answer it, not just put seven labels in order. |
| **Time, first pass** — 2B L2 | `现在几点？` / `现在……点。` | Set/read an analog clock after audio; choices include nearby times so the child must notice the hands. |
| **Stationery** — 2B L3 | `这是我的……。`; `……有……`; colour + `的` + school object; relevant measure words. | Pack a pencil case from an audio instruction, e.g. a coloured object and quantity; sentence-builder is the reinforcement step. |
| **Classroom** — 2B L4 | `教室里有……。`; `……在……。` with classroom furniture. | Find-and-tap from a busy classroom, then choose/build the location sentence. |
| **Big and small** — 2B L6 | `……大。` / `……小。` and a simple contrast. | Compare two same-kind objects that swap sides and sizes each round; never make the answer depend on fixed left/right position. |
| **Dates** — 3A L2 | `几月几号？` / `……月……号（日）。` | Listen to a date and tap it on a simple calendar; build a date from shuffled month/day chips. |
| **Birthdays** — 3A L3 | `生日快乐！`; `我的生日是……月……号。` | Match an invitation/cake calendar date to the correct spoken date; order a birthday exchange. |
| **Nationality** — 3A L5 | `你是哪国人？` / `我是……人。` | Listen to a child introduce themself, then choose the matching country; build the answer from country + 人. Keep this about people, not flag drilling. |
| **Clothes, second pass** — 3A L7 | `他 / 她穿……。`; colour + `的` + clothes; `穿 / 戴` distinction. | Outfit listener: select the described outfit from same-shape clothes with randomized colours. |
| **Schoolbag** — 3B L1 | `书包里有……。` / `书包里没有……。`; `文具盒里有……。` | Pack/unpack a backpack in response to audio, including a true `没有` contrast. |
| **Classroom and positions** — 3B L2–3 | `A 在 B 上面 / 下面 / 里面 / 外面 / 前边 / 后边 / 左边 / 右边。` | Move a pictured object into the spoken location, then confirm with the full sentence. This must be a spatial task, not word matching. |
| **Hobbies, second pass** — 3B L4 | `我喜欢……。` / `我会……。` with singing, dancing, swimming, skating, drawing, and games as applicable. | Listen to a short peer-survey answer and place it on a “likes/can do” board. The two patterns need deliberate contrast. |
| **Food and drink** — 3B L5 | `我喜欢吃……。` / `我喜欢喝……。` | Sort a randomized food/drink selection, then hear and complete a preference sentence. |
| **Vegetables** — 3B L6 | Name vegetables and use them in food descriptions; connect colours where the book does. | Gather ingredients for a simple meal from an audio shopping list; confirm each with a complete phrase. |
| **Nature** — 3B L7 | `天上有……。` / `地上有……。`; then combined descriptive lines such as `地上有绿树、红花和小草。` | Audio-led tap in a day/night scene: target can be sky/ground + item; follow with a small sentence-builder that changes the noun. A passive replay card is insufficient. |
| **Languages** — 4A L2 | `你会说……吗？` / `我会说……。` | Choose the language a child says they speak, then order question and answer. Keep country and language as separate concepts. |
| **Time, second pass** — 4A L3 | Exact times including `……点零……分`, `一刻`, `半`, and time-of-day terms. | Listen to a time, set the clock, and choose the matching time-of-day sun position. |
| **Daily routine** — 4A L4 | `……点……。` for wake up, brush teeth, school, meals, and bedtime. | Put a child’s routine scenes in chronological order, then attach a spoken time sentence to each. |
| **Lunch** — 4A L5 | `我中午吃……。` and a short lunch preference/description. | Build a lunch tray from an audio sentence; use food, drink, and colour only when each is meaningful. |
| **Transport** — 4A L6 | `坐……去……。` / `骑……去……。` / `走路去……。` | Pick a vehicle and destination from audio, then build the route sentence. Do not treat every vehicle as interchangeable with `坐`. |
| **Hungry and thirsty** — 4A L7 | `我饿了。` / `我渴了。` / `我想吃 / 喝……。`; `好吃。` where appropriate. | Situation chooser: identify hungry vs thirsty, then choose a fitting food/drink response and play the complete exchange. |
| **Weather** — 4B L1 | `下雨了。` / `下雪了。` / `今天很冷 / 热。` / `今天刮大风。` / `今天是晴天。` | Listen-and-choose among four mixed weather scenes, then a dress-for-weather decision. Re-randomize scene order and clothing colours. The current Weather page has scenes and notes, but no dedicated interactive practice yet. |
| **Clothes and weather** — 4B L2 | `他 / 她穿……。`; colour + `的` clothes; connect clothing choice to weather where the book does. | A weather-led outfit task with a separate descriptive listening round. This should reuse, not duplicate, the Weather vocabulary. |
| **My room** — 4B L3 | `房间里有……。`; furniture and location descriptions. | Furnish a room from audio instructions, then validate each `房间里有……` / location sentence. |
| **Hobbies and leisure** — 4B L4, L7 | `放学后……。` / `周末……。`; preference and ability language in a free-time context. | Choose a child’s after-school/weekend schedule from audio; then build one personalized sentence. This is a progression beyond the 2A reading card, not a repeat of it. |
| **Our school** — 4B L5 | `学校有……。`; name places such as classroom, library, playground, cafeteria, and hall. | School-map audio quest: child taps the named place, then completes `学校有……`. |
| **School subjects** — 4B L6 | `我喜欢……课。` / `我不喜欢……课。`; use `去上……课` and `在上……课` if presented in the scene. | Listen to student preference/whereabouts, then select the matching subject scene. Keep `去` and `在` as a deliberate contrast. |

## What the audit changes for the current build

1. **Do not mark a topic done from its asset inventory.** The previous “all strong” asset matrix remains useful for production planning, but it is not a content-completion report.
2. **Build by sentence family, not by isolated lesson pages.** For example, colour must appear in clothes, school things, food, and nature where the books use it; weather should feed the later clothes lesson.
3. **Every returned topic needs a new language job.** Repeating `我喜欢……` in 2A, 3B, and 4B without new context or practice is not progression.
4. **Prioritize the interaction gaps that block real use.** The highest-priority next work is Weather, Nature, colours-in-context, clothing-for-weather, and the hobby/leisure progression.

## Recommended implementation order

1. **Finish the World Around Us cluster:** Weather practice, Nature find-and-build practice, and the clothes/weather bridge.
2. **Audit the repeated language clusters together:** Colours → stationery/clothes/nature; `有 / 没有` → family/schoolbag/classroom/room; `喜欢 / 会` → reading/hobbies/leisure; time → clock/routine.
3. **For each remaining topic, create a small lesson contract** before coding: scene list, book words, useful-note patterns, target practice, randomization rule, and asset gaps.
4. **Only then generate missing art.** A new image is justified when the required contrast cannot be understood from an existing scene.

## Current Weather contract (immediate next implementation)

The Weather page should retain the four scene cards and its two Useful notes. Its missing practice should be:

- **Listen and choose:** four weather scenes, shuffled every round; play one of the six book sentences and ask the child to tap the matching scene.
- **Dress for the weather:** show the selected weather scene and three large outfit choices; choose an appropriate outfit, then hear a full sentence such as `下雪了。今天很冷。穿外套、帽子和手套。`
- **No duplicate generic word panel:** the page already teaches its book sentences in its scenes; the practice should operate on those sentences rather than re-listing `下雨了` below the lesson.
