## Final page decisions

- **Scope:** `唱歌`, `跳舞`, `游泳`, `滑冰`, and `滑雪`; ask `你喜欢…吗？` and hear `我喜欢…`.
- **Navigation:** Music & Movement is a sibling card in Play & Hobbies, mapped to Book 3B Lesson 4. It is not an in-page child shelf below the 2A lesson.
- **Scene:** Five cards in a standard 2×3 grid. Every visible scene image uses the same 4:3 frame.
- **Scene language:** Match the people actually visible. The chorus supports `我们爱唱歌。`; Luna’s solo dance scene supports `她爱跳舞。`.
- **Assets:** Noah’s skating scene fills the only missing activity. Luna’s portrait dance asset was retained but replaced for this page with a 4:3 landscape scene so the grid needs no aspect-ratio workaround.
- **Book words:** Text only; the scenes already supply the visual cues.
- **Practice:** Build a question, explicitly using `吗`. The green arrow **New game** button starts a random draw from the full five-activity set. After a correct answer, show only the completed question and reply—hide unused distractors such as `看书`.

## Reusable findings

- A later lesson gets its own page/card when it owns different scenes and practice; do not branch inside an earlier completed lesson.
- Treat a page grid’s display ratio as a layout requirement. Select or generate assets to fit it, rather than exposing mixed source ratios with `contain`.
- A question game must say it is building a question and name the required question marker.
