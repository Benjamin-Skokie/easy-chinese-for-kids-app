# Page Build Logs

This directory keeps detailed, page-specific iteration records: redirects, rejected assets, and local decisions that are useful when resuming that same page.

Name each file `<topic>_<book>_<lesson>.md`, for example `what_i_like_2a_5.md`. Put reusable discoveries in [development_log.md](../development_log.md), and update [lesson_page_workflow.md](../lesson_page_workflow.md) whenever they change the active process.
