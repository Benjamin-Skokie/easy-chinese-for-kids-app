# Book Content Asset Review

Last updated: 2026-08-03

Purpose: book-first companion view for manually checking whether the topic mapping misses lesson content.

Status: detailed manual review view. It overlaps [learn_by_books_asset_mapping.md](./learn_by_books_asset_mapping.md), but keeps culture-by-book review rows and fuller audit detail.

Primary data file: [book_content_asset_review.json](./book_content_asset_review.json)

Use this review flow:

- Open the matching PDF/contact sheets for one book.
- Check each listed lesson title, vocabulary, patterns, and asset gaps.
- Add missing content to the source JSON mapping, then regenerate this review file if needed.
- Do not copy textbook illustrations or exact workbook pages into product assets.
