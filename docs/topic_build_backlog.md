# Topic Build Backlog

Last reviewed: 2026-08-18

This is the short, project-wide list of work that is easy to lose between
individual lesson builds. It is a planning index, not a replacement for a
topic contract: before starting an item, read or create the matching file in
[`lesson-contracts/`](./lesson-contracts/), confirm the book evidence, and
then update both records when the work is complete.

## How to maintain this list

- A **new topic** needs its own contract before it is built.
- A **partial topic** already has a live page; tick it off here only when its
  contract's intended cross-book coverage is complete.
- An **asset integration** is optional. Do not use an asset simply to make the
  library look complete; it needs a clear learning job.
- If a later book lesson has its own scenes, language job, and practice, make
  it a sibling page rather than extending an unrelated completed page.
